# agentlens

Claude Code 세션을 실시간으로 모니터링하는 TUI 도구입니다. 도구 호출 타임라인과 에이전트/스킬 스폰의 실시간 플로우차트를 함께 표시하며, 중첩 서브에이전트 트리와 병렬 인스턴스 뷰를 지원합니다.

```
┌──────────────────────────────────────┬──────────────────────────────────────┐
│ Timeline                             │ Flowchart                            │
│ ───────────────────────────────────  │ ──────────────────────────────────   │
│ ts        tool      agent  status    │        ┌──────┐                      │
│ 14:02:01  Task      main   ✓  1205   │        │ main │                      │
│ 14:02:03  Task      main   ✓  4708   │        └───┬──┘                      │
│ 14:02:10  Read      exec   ✓    12   │            │                         │
│ 14:02:11  Edit      exec   ✓    45   │   ┌────────┼──────────┐              │
│ ...                                  │   ▼        ▼          ▼              │
│                                      │ ┌─────┐ ┌──────┐  ┌────────┐         │
│                                      │ │plan │ │ exec │  │ critic │         │
│                                      │ │(x3) │ │[Rd4] │  │        │         │
│                                      │ │Rd12 │ └──────┘  └────────┘         │
│                                      │ └─────┘                              │
├──────────────────────────────────────┴──────────────────────────────────────┤
│ session: b0709256-...jsonl [slug]  nodes: 5 edges: 4  [all/LR/H]           │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 주요 기능

- **실시간 테일링**: `watchfiles`를 통해 메인 Claude Code 세션 JSONL을 라이브 테일링 (표준 라이브러리 폴링 폴백 지원) — 새 이벤트가 ~1초 내에 표시됩니다.
- **타임라인 패널**: 세션의 모든 tool_use / tool_result 이벤트를 스크롤 가능한 DataTable로 표시하며, 플로우차트와 교차 하이라이트됩니다.
- **플로우차트 패널**: Agent/Task/Skill 호출의 실시간 방향 그래프. 부모/자식 엣지, `(xN)` 중복 카운터, 서브에이전트별 도구 사용 뱃지(예: `Rd12 Ed5`), 상태별 색상 코딩(실행 중 / 완료 / 오류)을 표시합니다.
- **최대 깊이 5의 중첩 서브에이전트 트리**: 서브에이전트가 Skill을 통해 또 다른 서브에이전트를 스폰하면, 중첩된 스폰이 `main`에 합쳐지지 않고 플로우차트에서 자식 노드로 표시됩니다.
- **모드별 인스턴스 뷰**: `[running]` 모드에서는 같은 에이전트 타입의 병렬 스폰이 인스턴스별 도구 카운트와 함께 별도 박스로 렌더링됩니다. `[all]` 모드에서는 `(xN)` 카운터와 합산된 내역으로 하나의 박스에 집계됩니다.
- **스티키 러닝**: 다음 실제 사용자 프롬프트가 있을 때까지 노드가 시각적으로 녹색을 유지하므로, 빠른 에이전트가 확인하기 전에 "완료" 상태로 깜빡이지 않습니다. 백그라운드 태스크 알림, 훅 리마인더, `<teammate-message` 행, 서브에이전트의 자체 사용자 행은 플러시 로직에서 필터링됩니다.
- **인스턴스별 드릴다운** (`d` 키): 클릭한 병렬 인스턴스의 특정 도구 히스토리를 모달로 열어 확인 — 각 인스턴스는 자체 서브에이전트 JSONL 파일을 엽니다.
- **세 가지 직교 토글**:
  - `m` — 모드 (전체 ↔ 실행 중만)
  - `o` — 방향 (위→아래 ↔ 왼→오른쪽)
  - `p` — 패널 (가로 ↔ 세로)
- **스크롤 가능한 플로우차트**: 마우스 휠 + 키보드 (PgUp/PgDn, Shift+H/L, Home/End).
- **세션 피커**: 같은 slug 디렉터리에 여러 JSONL이 있을 때 실행 시 표시됩니다. `--latest`로 우회 가능. 실행 중 `s`를 눌러 재시작 없이 같은 디렉터리의 다른 세션으로 전환 — 타임라인과 플로우차트가 새 세션에 맞게 자동으로 재구성됩니다.
- **`Shift+S`를 통한 경로 직접 입력**: 전체 JSONL 경로 또는 세션 ID / 접두어(`b0709256`)를 받는 입력 모달을 엽니다. ID를 모든 프로젝트 하위 디렉터리에서 glob으로 찾아 매치하므로, slug 기반 피커가 실패할 때도(예: Windows/git-bash에서 경로 형식이 다를 때) 올바른 세션을 복구할 수 있습니다.
- **Windows / git-bash 호환성**: slug 디렉터리 조회가 실패하면 로케이터가 각 JSONL의 `cwd` 필드를 기반으로 매칭하는 폴백을 사용하므로, 이 도구가 기본적으로 지원하지 않는 플랫폼에서도 세션이 정상적으로 해결됩니다.
- **서브에이전트 왓처**: 세션의 `subagents/` 디렉터리 아래에 새 `agent-*.jsonl` 파일이 생성될 때 자동으로 발견하고 테일링합니다. `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1`로 스폰된 팀 에이전트는 `.meta.json` 사이드카에서 OMC 이름(예: `verifier-a`, `executor`)으로 해석됩니다.
- **Turn Summary — 토큰 사용량 분해** (v0.8.1): Turn Summary 모달(`m` 키)에서 스킬 및 에이전트별 토큰 소비량을 계층 구조로 표시합니다. 스킬 스팬은 하위 에이전트를 4칸 들여쓰기로 나열하며, 독립 에이전트는 `agents (N)` 섹션 아래에 표시됩니다. `Total`은 이중 집계를 방지하기 위해 리프 합산값만 사용합니다.
- **활동량 스파크라인** (Activity Sparkline) in the status footer: 마지막 60초 동안의 이벤트/초를 8단 블록 문자(▁▂▃▄▅▆▇█)로 표시하는 롤링 히스토그램이며, `peak: N/s` 레이블을 포함합니다. 화면이 좁을 때는 자동으로 숨겨집니다.
- **방어적 설계**: 스키마 허용 파서(알 수 없는 필드에서 예외를 던지지 않음), 적대적 입력에 대한 MAX_NODES / MAX_BUFFER_BYTES / MAX_RAW_LINE 제한, 터미널 안전을 위한 ANSI 이스케이프 문자 제거.

## 설치

Python 3.11+ 필요.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
```

## 실행

```bash
agentlens                            # cwd의 slug 디렉터리에서 가장 최신 세션 자동 선택
agentlens --latest                   # 피커 건너뛰고 가장 최신 세션 선택
agentlens --session PATH             # 특정 JSONL 파일 직접 연결
agentlens --project-root PATH        # 다른 cwd로부터 slug 계산
agentlens --self-test                # 한 프레임 렌더링 후 종료 코드 0으로 종료 (CI 스모크 테스트)
agentlens -v                         # 상세 로깅
```

`watchfiles`를 설치할 수 없는 경우, `AGENTLENS_BACKEND=polling`을 설정하여 표준 라이브러리 폴링 테일러를 강제 사용합니다:

```bash
AGENTLENS_BACKEND=polling agentlens
```

키 바인딩, 모드 의미론, 드릴다운 흐름, 아키텍처 노트를 포함한 전체 사용 가이드는 [`docs/USAGE.md`](USAGE.md)를 참조하세요.

## 수동 검증

원본 스펙의 완료 기준에는 자동화 스위트 외 두 가지 수동 검사가 포함되어 있습니다.

### M-AC8-idle (30초 초과 시 푸터에 `— session idle` 표시)

**상태:** PASSED — `tests/test_idle_footer.py`의 자동화 테스트로 커버됨 (4개 테스트, 모두 통과). 테스트는 `time.monotonic`을 몽키패치하여 `_refresh_idle_footer`를 직접 검증하며, 양성 케이스, 30초 미만 음성 케이스, 신선한 세션(아직 이벤트 없음) 엣지 케이스, 30.000 대 30.001초의 정확한 경계를 커버합니다.

### M-AC11 (유휴 CPU ≤ 2%)

**상태:** PASSED — 2026-04-09 측정 완료.

측정 방법: Python 하네스 내에서 `pty.fork()`를 통해 `agentlens` 실행, `AGENTLENS_BACKEND=polling`으로 빈 세션 파일에 연결, 3초 마운트 지연 후 10초간 `ps -o pcpu=`로 초당 1회 샘플링.

결과:

| 지표 | 값 | 목표 |
|------|-----|------|
| 유휴 CPU 평균 (10초 윈도우) | **0.16 %** | ≤ 2 % |
| 유휴 CPU 최대 (10초 윈도우) | **0.30 %** | ≤ 2 % |
| RSS | **40.7 MB** | — |

목표치를 충분한 여유를 두고 달성. 폴링 루프 또는 set_interval 속도가 변경되면 재측정하세요.
