# TUI UX Spec

Textual 기반 agentlens TUI의 UX를 설계한다.

## 설계 프로세스

### Step 1: 기존 UX 감사

새 기능 설계 전에 기존 상태를 파악한다:

1. `app.py`에서 현재 키바인딩 전체를 읽는다
2. 각 패널의 로컬 키바인딩을 확인한다
3. 현재 화면 레이아웃(`app.tcss`)을 파악한다
4. 기존 사용자 흐름(모달 열기/닫기, 패널 전환)을 이해한다

### Step 2: 사용자 흐름 설계

기능의 시작부터 끝까지 사용자 관점에서 step-by-step으로 기술한다:

```
1. 사용자가 Timeline에서 이벤트를 보고 있다
2. `f` 키를 누른다
3. 하단에 필터 입력창이 나타난다 (포커스 자동 이동)
4. "tool_use"를 입력한다
5. Timeline이 실시간으로 필터링된다
6. `Escape`를 누르면 필터가 해제되고 전체 목록으로 복귀한다
```

### Step 3: 키바인딩 할당

키바인딩 할당 규칙:

1. **충돌 확인 필수** — `app.py`와 모든 패널의 기존 바인딩과 충돌하지 않는 키를 선택한다
2. **직관성** — 기능의 영문 첫 글자 또는 관례적 키 (f=filter, /=search 등)
3. **수식키 계층** — 단일 키 → Shift+키 → Ctrl+키 순서로 할당
4. **글로벌 vs 로컬** — 어디서든 동작해야 하면 app.py, 특정 패널에서만이면 해당 패널

### Step 4: 와이어프레임 작성

ASCII로 80×24 기준 레이아웃을 작성한다:

```
┌─ Header ────────────────────────────────────────────────────┐
│ agentlens v0.x.x │ session: abc123 │ events: 1,234         │
├─ Timeline (60%) ─────────────┬─ Flowchart (40%) ───────────┤
│ # │ Time  │ Type    │ Agent │ ┌──────┐    ┌──────┐        │
│ 1 │ 12:01 │ tool_use│ main  │ │ main ├───→│ sub1 │        │
│ 2 │ 12:02 │ result  │ main  │ └──────┘    └──────┘        │
│ > │ 12:03 │ message │ sub1  │                              │
│   │       │         │       │                              │
├─ [NEW: Filter Bar] ─────────┴──────────────────────────────┤
│ Filter: tool_use█                                    [ESC] │
├─ Footer ───────────────────────────────────────────────────┤
│ m:mode o:panel d:detail f:filter s:session q:quit          │
└────────────────────────────────────────────────────────────┘
```

before/after를 모두 그려서 변경점을 시각적으로 보여준다.

### Step 5: Textual 컴포넌트 선택

| 용도 | 추천 컴포넌트 | 사유 |
|------|-------------|------|
| 목록/표 | DataTable | 기존 패턴, cross-highlight 지원 |
| 텍스트 입력 | Input | Textual 빌트인, 포커스 관리 용이 |
| 정보 표시 | Static / RichLog | 읽기 전용 컨텐츠 |
| 선택 목록 | ListView / OptionList | 항목 선택 |
| 팝업 | ModalScreen | 기존 모달 패턴 따름 |
| 토글 | Switch / Checkbox | 설정값 |
